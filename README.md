## ✨ Tính Năng Nổi Bật của CV

- 🎨 **Thiết kế chuẩn UI/UX:** Tông màu hiện đại, font chữ Plus Jakarta Sans sắc nét, bố cục khoa học 2 cột.
- 🌓 **Chế độ Sáng / Tối (Dark / Light Mode):** Tự động lưu trạng thái lựa chọn của người dùng.
- 🖨️ **Tối ưu In ấn & Xuất PDF A4:** Tích hợp nút in một chạm (`window.print()`), đã cấu hình `@media print` giúp CV luôn gọn gàng, vừa vặn trang giấy.
- 📱 **Responsive 100%:** Hiển thị mượt mà trên Desktop, Laptop, Máy tính bảng và Điện thoại.

## 📂 Cấu Trúc Thư Mục

```text
├── index.html        # Trang CV chính (Hiển thị trực tiếp trên GitHub Pages)

```

## 🚀 Hướng Dẫn Sử Dụng & Xem CV

1. **Mở trực tiếp trên máy:** Nhấp đúp vào file `index.html` hoặc `cv.html` để xem trên trình duyệt.
2. **Kích hoạt GitHub Pages (Xem online miễn phí):**
   - Truy cập vào Repository trên GitHub: `Settings` > `Pages`.
   - Tại mục **Branch**, chọn branch `main` và thư mục `/ (root)`, nhấn **Save**.
   - Trang CV của bạn sẽ có link online dạng:  
     `https://duyhwng2301.github.io/Ki-u-Duy-H-ng/`
